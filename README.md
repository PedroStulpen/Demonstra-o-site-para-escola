# Escola Demo (Angular)

Site de demonstração de uma escola: login, perfil do usuário, cadastro de alunos e lançamento de notas.
Sem backend: os dados ficam no `localStorage` do navegador (veja `src/app/services`).

## Rodar
```bash
npm install
npm start   # http://localhost:4200
```
Login de demonstração: `admin@escola.com` / `123456`

## Estrutura
- `pages/login`, `pages/home` (usuário), `pages/alunos` (+ `dialog-aluno`), `pages/notas`
- `shared/navbar` — menu superior (offcanvas no mobile)
- `services` — `AuthService`, `AlunoService`, `NotaService` (trocar por `HttpClient` quando houver API)
